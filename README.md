# Interactive Anagram Finder

Interactive Anagram Finder is a command-line Java program that helps you build an anagram from a word or phrase. It loads candidate words from the included `20k.txt` dictionary. After you enter a phrase, it shows words that can be made from the letters you still have, arranged in columns. Choose a word to add it to your solution, and the program removes that word's letters before displaying updated choices. Continue selecting words until every letter is used, or enter `.` to view the next page of candidates.
